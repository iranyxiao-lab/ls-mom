# Proposal：前端现代化与低操作成本交互

## Why

LS-MOM 的主要用户是班组长、操作工、设备与质量人员和实施顾问，他们大多不是 IT 人员，常常在车间、手机或平板上用碎片时间操作。`bootstrap-ls-mom-mvp` 规定了每个页面"有什么"，但没有约束"用起来多费劲"。如果沿用 RuoYi 管理台默认的"菜单→列表→弹窗表单→确认"模式，一次填报要 6～10 次点击，现场就会退回纸质和 Excel。现在前端还没写，正适合先定下统一的设计系统和交互规范，避免以后逐页返工。

## What Changes

- 新增统一设计系统：设计令牌（颜色、圆角、间距、字号、阴影、动效）、明暗主题、紧凑／舒适两档密度、WCAG 2.1 AA 对比度与键盘可达、响应式断点，所有业务页面和 Schema 渲染器都只使用令牌。
- 改造应用外壳：按角色定制的首页工作台、全局命令面板（Ctrl/⌘＋K，搜索菜单、单据编号、对象和动作）、收藏与最近访问、多页签、面包屑、通知抽屉、状态完整的空态／加载／错误页。
- 新增高效录入模式：智能默认值（当前人员、组织、班次、时间，记住上次的选择）、草稿自动保存与恢复、实时校验和就近错误提示、全键盘录入、从 Excel 粘贴到子表、扫码填字段、批量编辑、乐观更新。
- 新增列表交互规范：保存视图（筛选＋列＋排序）、列自定义、快速筛选芯片、行内编辑草稿、批量操作栏、抽屉详情（不离开列表）、虚拟滚动、骨架屏。
- 新增现场移动端体验：给操作工的移动工作台（今日任务、一键开工／报工、拍照、扫码、语音转文字说明），触控目标 ≥44px，弱网下排队离线草稿，单手可操作。
- 新增引导式流程：每张单据显示"下一步做什么"、待办在抽屉中直接办理、按风险选确认方式（低风险操作可撤销，高风险二次确认并说明后果）、错误提示可操作、首次使用引导、上下文帮助。
- 新增设计器易用性：从模板或 Excel 表头一键生成台账草稿、所见即所得、发布前给出问题清单和一键定位、用自然语言描述字段（LLM 生成草稿后人工确认）。
- 新增 UX 质量门禁：关键任务操作步数预算、性能预算（LCP、交互延迟）、自动化无障碍检查、视觉回归、可用性测试流程。
- 不改变后端契约：所有交互仍走 Operation／FormSchema／节点字段策略，前端便利功能不绕过服务端校验。

## Capabilities

### New Capabilities

- `ui/design-system`：设计令牌、主题与密度、排版、图标、动效、无障碍与响应式基线。
- `ui/app-shell-navigation`：角色首页、命令面板、全局搜索、收藏与最近访问、页签、通知、空态／错误态。
- `ui/efficient-data-entry`：智能默认值、草稿自动保存、实时校验、键盘录入、粘贴导入、扫码、批量编辑。
- `ui/list-interactions`：保存视图、列自定义、快速筛选、行内编辑、批量操作、抽屉详情、大数据量渲染。
- `ui/mobile-field-ops`：移动工作台、一键报工、拍照／扫码／语音、离线草稿队列、触控与单手操作。
- `ui/guided-workflows`：下一步动作提示、抽屉内办理、分级确认与撤销、可操作的错误反馈、新手引导与上下文帮助。
- `ui/designer-usability`：表单／流程设计器的模板起步、Excel 生成台账、自然语言辅助、发布问题清单。
- `ui/ux-quality`：操作步数预算、性能预算、无障碍与视觉回归检查、可用性验证。

### Modified Capabilities

（无。`bootstrap-ls-mom-mvp` 的 spec 尚未归档进 `openspec/specs/`；本 change 只补充体验层要求，不改其中任何行为。）

## Impact

- **前端**：`plus-ui` 的布局、主题、路由与通用组件层；`SchemaForm／SchemaTable／SchemaDetail` 渲染器；表单与流程设计器外壳；新增移动端路由组 `/m`。
- **依赖**：保留 Vue 3＋TypeScript＋Element Plus（沿用 bootstrap D7）；新增 UnoCSS＋Iconify（MIT）、VueUse（MIT）、vxe-table（MIT，可编辑表格与虚拟滚动）、Vant 4（MIT，仅移动端）、pinyin-pro（MIT）、vite-plugin-pwa（MIT）、idb-keyval（Apache-2.0）、@zxing/browser（Apache-2.0，扫码）、driver.js（MIT，新手引导）、SheetJS 社区版（Apache-2.0）、Storybook（MIT）；测试期使用 axe-core（MPL-2.0）、Lighthouse CI（Apache-2.0）、size-limit（MIT）。
- **后端**：少量支持性接口——用户偏好（保存的视图、收藏、默认值记忆）、全局搜索、草稿存储——全部经 Operation／命名 Query 暴露。
- **关系**：依赖 `bootstrap-ls-mom-mvp` 的前端骨架（其任务 2、7.7、8.4、8.6、10.4、11.3、13.3），应在这些任务开始前或同时落地设计系统，避免返工。
