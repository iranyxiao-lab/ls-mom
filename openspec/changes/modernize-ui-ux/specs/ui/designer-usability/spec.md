# Spec Delta

## Purpose

降低实施人员用表单与流程设计器交付台账的成本：从模板或已有 Excel 起步而不是从空白开始，边做边预览，发布前一次看清所有问题。

## ADDED Requirements

### Requirement: 从模板起步
新建台账或流程时 SHALL 提供模板库（如借还登记、点检表、整改单、简单审批），选择后生成可编辑的 Concept、表单、列表和流程草稿。

#### Scenario: 用借还模板
- **WHEN** 实施人员选择"借还登记"模板并改名
- **THEN** 生成包含主子表、借还状态与审批流程的完整草稿

### Requirement: 从 Excel 生成台账
实施人员 SHALL 能上传 Excel，系统根据表头和样例数据推断字段名、类型、字典候选与必填，生成台账草稿供确认；推断结果逐项可修改。

#### Scenario: 推断字段
- **WHEN** 上传含"日期、设备编号、检查结果（正常/异常）"表头的点检表
- **THEN** 草稿中"日期"为日期类型、"设备编号"建议为设备引用、"检查结果"建议为二值字典

### Requirement: 自然语言辅助
设计器 SHALL 允许用自然语言描述需要的字段或规则（如"严重程度为高时必须填立即措施"），由 LLM 生成对应配置草稿并高亮变更，实施人员确认后才应用。

#### Scenario: 生成条件必填
- **WHEN** 输入上述描述
- **THEN** 规则面板出现对应的条件必填规则草稿，确认前不生效

### Requirement: 所见即所得
设计器画布 SHALL 与运行时外观一致；修改属性后预览在 300ms 内更新，可一键切换桌面／移动／详情／打印和流程节点视角。

#### Scenario: 切换节点视角
- **WHEN** 实施人员切换到"车间审核"节点视角
- **THEN** 画布中不可编辑字段显示为只读样式

### Requirement: 发布前问题清单
点击发布 SHALL 先展示全部校验问题（错误与警告分级），每项可一键定位到对应字段、规则或节点；只有错误为零时才能发布。

#### Scenario: 一键定位
- **WHEN** 问题清单显示"节点 CONFIRM 引用了不存在的字段 confirmNote"
- **THEN** 点击该项后流程设计器选中该节点并打开字段策略面板

### Requirement: 安全的试运行
设计器 SHALL 提供沙箱试填：用当前草稿填写并走完流程，不写入正式数据，结束后可一键清除试运行数据。

#### Scenario: 试运行审批
- **WHEN** 实施人员以模拟角色走完提交→审核→确认
- **THEN** 正式库中没有任何试运行记录
