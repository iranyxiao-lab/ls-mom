# Spec Delta

## Purpose

提供无 BOM 也能闭环的轻生产能力：生产需求、班次安排、分派、填报、产出与物料记录、交接班和经营看板，形成"需求→工作→分派→填报→确认→交接班／看板"的完整链路。

## ADDED Requirements

### Requirement: 生产需求
系统 SHALL 支持登记月／周／日／临时生产需求，只需描述、可选数量与单位、期望完成日期和附件；需求 SHALL 可转为一个或多个生产 WorkItem。

#### Scenario: 文字需求转工作
- **WHEN** 车间主任登记"周三前完成 A 线清洗与 200 件组装"并转为两条工作
- **THEN** 生成两条 PRODUCTION 类型 WorkItem 并关联该需求

### Requirement: 无制造主数据的完整闭环
从需求创建到工作完成确认的全过程 SHALL NOT 要求存在 BOM、Routing 或 Warehouse。

#### Scenario: DOM-01 验收
- **WHEN** 在空的制造主数据环境中执行需求→工作→分派→填报→确认
- **THEN** 全流程成功，工作状态为 DONE

### Requirement: 班次安排
系统 SHALL 支持按班组、日期、班次安排工作项，并以列表和简单看板展示；SHALL NOT 提供自动排程优化。

#### Scenario: 拖动调整班次
- **WHEN** 班组长将一条工作从早班移到中班
- **THEN** 工作的计划班次更新，冲突按 Profile 提示或阻断

### Requirement: 产出与物料记录
系统 SHALL 支持记录产出（数量、单位、时间、人员、说明、可选批次）和物料记录（领用、投料、退料、转移）；默认 SHALL NOT 自动核销库存或校验物料平衡。

#### Scenario: 默认不核销
- **WHEN** 记录投料 50kg 但未记录领用
- **THEN** 记录成功，不产生库存差异错误

### Requirement: 交接班
交接班 SHALL 汇总当班工作、未完成事项、异常、DCS 摘要与附件；LLM 可生成摘要草稿，但交班人确认后才发布，接班人确认后交接完成。

#### Scenario: 双方确认
- **WHEN** 交班人确认摘要、接班人确认接收
- **THEN** 交接班记录为已完成，未完成事项自动出现在接班班组工作板

#### Scenario: 草稿未确认
- **WHEN** LLM 生成摘要但交班人未确认
- **THEN** 接班人看不到该交接班记录

### Requirement: 生产运营工作台
系统 SHALL 提供生产需求板、工作板（按状态／班组／日期／风险）、分派台、移动填报和交接班页面。

#### Scenario: 移动填报拍照
- **WHEN** 操作工在手机端填报进度并拍照
- **THEN** 照片作为证据附件关联到该填报

### Requirement: 经营看板
经营看板 SHALL 展示工作量、按期完成率、异常数、产出、人工和设备状态，所有指标来自已注册指标并可钻取。

#### Scenario: 看板钻取
- **WHEN** 点击按期完成率
- **THEN** 显示参与计算的工作明细
