# 错误页

| 情况 | 显示 | 下一步 |
| --- | --- | --- |
| 地址是系统页面，但当前用户没有该菜单 | 403「没有访问权限」：页面路径（如"系统管理 / 用户管理"）、缺少的权限编码、追踪编号 | 填写理由后「申请权限」：通知全部超级管理员（系统消息，链接到角色管理）；同一人同一页面 24 小时内只发一次 |
| 地址不存在 | 404「找不到这个页面」 | 返回首页、返回上一页，或用命令面板搜索 |
| 服务出错 | `/500`「服务出错了」，带追踪编号 | 重试；把追踪编号发给管理员 |
| 断网 | 页面顶部常驻提示；页面资源取不到时跳到 `/offline` | 恢复网络后「重试」回到原页面 |

- **追踪编号**：后端每个响应带 `X-Trace-Id`（`TraceIdFilter`），前端记住最近一次（`utils/trace.ts`），错误提示后面附上。
- **接口**：`GET /api/ui/access/page?path=` 返回页面名称、路径与所需权限（查 `sys_menu`）；`POST /api/ui/access/request {path, reason}`。
- `/500` 与 `/offline` 随主包加载且免登录，断网时也能显示。
- **测试**：`AccessServiceTest`，`tests/ui/app/errors.spec.ts`。
