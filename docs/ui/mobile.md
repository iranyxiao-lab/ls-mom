# 手机版（/m）

给车间现场的操作工、点检员、维修工用：打开就是今天要做的事，几下完成报工、点检、报缺陷，弱网和断网也能用。

## 进入与切换

- 访问首页时按**设备宽度与用户类型**自动进入：窄屏（< 768px）进入手机版；现场岗位（角色 `operator`、`inspector`、`maintainer`、`repairman`）在平板宽度（< 1024px）也进入手机版。
- 手动切换：电脑版右上角用户菜单「切换到手机版」；手机版「我的」→「切换到电脑版」或选择「自动／手机版／电脑版」。选择存在服务端偏好 `uiMode`（`auto`／`desktop`／`mobile`），换设备登录后保持。
- `/index?desktop=1` 总是打开电脑版首页（测试与支持排查用）。
- 手机版不显示桌面管理菜单：顶栏（返回、标题、待同步数）、离线提示、底部导航（工作台、扫一扫、我的）。

## 页面

| 路由 | 页面 | 要点 |
|---|---|---|
| `/m` | 工作台 | 今日任务（本班次在前，按班次、紧急程度 1 最急、计划开始排序），每张卡片一个主按钮：已分派「开工」、进行中「报工」；待我确认；快捷动作报工、点检、报缺陷、扫一扫。今日任务缓存在本机，离线时显示缓存并注明时间 |
| `/m/report/:id` | 报工 | 只显示 MobileSchema 的字段（`ls.core.WorkReport` 已发布的 MOBILE 视图；没有时默认产出、进度、说明），数字用数字键盘与 ± 步进，「提交」固定在底部；照片可选 |
| `/m/inspect` | 点检 | 扫设备码直接打开分给自己的该设备待点检，逐项「正常／异常」或填读数（超限自动判异常），异常项一键生成缺陷草稿；可从设备直接「报缺陷」 |
| `/m/defect` | 报缺陷 | 从设备进入自动带出设备；描述可按住话筒说话，严重度一次点选，拍照；「提交」即登记。点检生成的草稿在这里补充照片后登记；「删除草稿」在页面顶部，不与「提交」相邻 |
| `/m/me` | 我的 | 离线待同步（失败的可看原因并丢弃）、界面模式、退出 |

## 渲染器的手机控件

`SchemaForm` 传 `platform="mobile"` 时字段改用 `MobileFieldWidget`（按需加载，不进电脑版首屏）：文字字段带语音按钮；数字用 Vant 步进器（44px 加减按钮、数字键盘）；6 个以内的选项平铺为大按钮一次点选，多的用底部选择器；日期用系统日期选择器；引用、附件等沿用电脑版控件。手机版可点击元素不小于 44×44px。

## 拍照、扫码、语音

- 拍照：长边压缩到 1600px（JPEG 0.8），可在照片上用手指标注（红笔、撤销一笔）。提交后作为证据附件（`EVIDENCE`）关联到当前单据，单据时间轴显示「上传现场证据：文件名」。
- 扫码：底部「扫一扫」用摄像头或扫码枪，也可手动输入编码；默认按设备码进入点检。
- 语音：浏览器支持 Web Speech API 时直接识别（中文）；不支持时回退到服务端语音识别——配置 `lsmom.speech.url`（接收 multipart 字段 `audio`，返回 `{"text": "..."}`，超时 `lsmom.speech.timeout-ms`，默认 15 秒）；两者都没有时不显示语音按钮。

## 离线

- 断网时报工照常填写，提交排入本机队列 `outbox-ui`（IndexedDB，含照片），卡片与顶栏显示「待同步」。每条带排队时生成的幂等键，恢复网络后按顺序自动提交，服务端幂等，不会重复生成报工。
- 同步时被拒（如任务已被班组长取消）标为「同步失败：任务已取消」，在「我的」查看并丢弃，不再重放。原因由 `GET /api/production/my-work-status?ids=` 查到（取消后分派已释放，任务不在数据范围内）。
- PWA：可添加到手机桌面，从 `/m` 全屏打开。Service Worker 预缓存应用外壳（index.html、入口样式、手机版页面），其余静态资源首次使用后缓存；接口不缓存。无网络打开时显示外壳、上次缓存的今日任务和离线提示（离线时用上次登录的身份显示）。

## 测试

- 单元：`tests/unit/mobile.spec.ts`（进入规则、今日任务排序、离线队列重放与失败）。
- 后端：`GatewayTest.时间轴包含现场证据附件_按时间与动作合并`。
- 端到端：`tests/e2e/mobile.e2e.mjs`（手机视口触屏：自动进入、本班次任务、开工、报工点击 ≤5、触控尺寸、照片压缩与标注、断网待同步与恢复、任务取消后同步失败、PWA 离线打开、扫码点检、异常生成缺陷草稿、从设备登记缺陷点击 ≤4、语音、切到电脑版）。
