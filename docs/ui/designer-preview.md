# 表单设计器：实时预览与视角切换

设计页工具栏「实时预览」在画布右侧打开预览栏，「预览」页使用同一视角：

| 视角 | 内容 |
|---|---|
| 桌面 | 录入表单（与运行时同一渲染器） |
| 移动 | 手机版单列表单 |
| 只读详情 | 记录详情页 |
| 打印 | 打印模板 |
| 流程节点 | 选择节点（名称取自绑定该表单的流程，如"车间审核"），按节点策略显示只读、可编辑、必填、隐藏 |

- 属性修改后 300ms 内更新预览：扩展属性面板的修改立即生效；设计器自带属性面板没有事件，每 150ms 读取一次。
- 节点视角里只读字段显示为文字并带浅底色，可编辑字段保留输入框，必填字段带必填标记；每个字段带 `data-access`（readonly / editable / required）。
- 节点策略面板显示"节点名（策略键）"；流程节点按流程中的顺序列出，只在表单里配置了策略的节点排在后面，`initiator` 显示为"发起人（退回修改）"。

接口：`GET /api/flow/form-nodes?formCode=`（绑定该表单的流程节点）。验证：`tests/e2e/designer-perspective.e2e.mjs`。
