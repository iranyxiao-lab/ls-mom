# 模板库：从模板新建台账应用

协同应用中心 →「变更发布」→「从模板新建」。不写代码，三步生成一个完整的台账应用草稿。

## 内置模板

| 模板 | 内容 | 审批 |
|---|---|---|
| 借还登记 | 借用人、日期、用途（外协须填外协单位）、用于设备、附件；借出明细子表 | 部门审核 → 确认归档 |
| 点检表 | 区域、日期、点检人、异常说明（有异常必填）、照片；检查项子表 | 班长复核 |
| 整改单 | 问题、严重程度（严重须写整改措施）、责任人、期限、相关设备、整改照片 | 验收 |
| 简单审批 | 申请事项、申请人、金额、理由、附件 | 审批 |

模板以 LS-IR 片段存放在 `ls-mom-pack/src/main/resources/lsmom-templates/*.yaml`（实体、字段、子表、审批节点、规则、样例值），
新增模板只需加一个 YAML 文件。Excel 推断的结果也是同样的片段，走同一个向导。

## 向导步骤

1. **选择模板**。
2. **基本信息**：应用名称、编码（如 `acme.loan`，同一编码再次生成会作为升级提交）、业务负责人、需求提出人；
   登记角色（谁可以新增和提交），每个审批节点的办理角色。
3. **预览并生成**：列出生成的全部 Pack 文件（清单、Concept、状态机、规则、表单、列表、审批流、黄金场景），可直接修改；
   默认同时建按钮权限并授予角色（审批流发布时会校验节点办理人具备办理权限）。点「生成草稿」提交为 ChangeSet。

生成的草稿和手写 Pack 一样：立即执行校验与依赖分析，再经升级演练（沙箱、回归、越权、升级）、批准后发布，不会直接生效。

## 生成规则

- 状态：草稿 → 审核中 → 已通过 / 已退回 / 已驳回；可撤回、退回后再提交。
- 审批节点按"角色且数据范围覆盖单据所属组织"分派，办理人一定能看到并办理这张单据。
- 撤回只在单据的流程区域办理（同时结束审批人的待办）；审批进行中，流程回调动作不能从列表或接口直接调用。
- 列表默认排序只用声明了可排序的字段；筛选项取声明了可查询的字段。
- 权限按钮挂在隐藏目录「<应用名称> 权限」下，用户重新登录后生效。

接口：`GET /api/pack-templates`、`POST /api/pack-templates/preview`、`/grants/plan`、`/grants`（需 `system:role:edit`）、`/draft`。
验证：`TemplateGeneratorTest`（四个模板安装后黄金场景与越权测试通过）、`tests/e2e/template-library.e2e.mjs`。
