# 键盘录入

`SchemaForm` 在录入表单里支持以下键盘操作。

| 按键 | 作用 |
|---|---|
| Enter | 跳到下一个可录入的字段。只读字段和附件不参与；多行文本里 Enter 是换行；下拉框展开时 Enter 选中高亮的选项；日期字段离开时按输入确认取值 |
| Enter（子表最后一行的最后一格） | 新增一行，并聚焦新行的第一格 |
| 「添加一行」按钮 | 新增一行，并聚焦新行的第一格 |
| Ctrl/⌘ + S | 保存草稿（`save` 事件），同时阻止浏览器另存网页 |
| Ctrl/⌘ + Enter | 提交（`submit` 事件）。通用台账优先执行 `submit` 动作，没有时执行第一个动作 |

- 选择类控件（下拉、字典、引用）都支持输入即搜索，方向键移动，Enter 选中第一个或高亮的候选。引用搜索只采用最后一次搜索的结果。
- 快捷键只在焦点所在的表单内生效；多个表单同时可见时，焦点所在的表单优先。
- 传入 `hotkeys` 时，表单底部显示快捷键提示，可在偏好中心关闭；传入 `autofocus` 时，打开后聚焦第一个字段。

快捷键的注册方式是 `useHotkeys(scope, { 'mod+s': fn })`，代码见 `src/utils/hotkeys.ts`。

端到端测试见 `tests/ui/app/keyboard-entry.spec.ts`：不用鼠标完成借还单的录入和提交。
