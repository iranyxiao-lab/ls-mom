# 子表从 Excel / WPS 粘贴

子表编辑器（`SubTableEditor`，基于 vxe-table，超过 200 行时启用虚拟滚动）支持把 Excel 或 WPS 中复制的多行多列直接粘贴进来。

## 怎么粘贴

- 点「从 Excel 粘贴」后按 Ctrl+V：追加到末尾，从第一列开始填。
- 在某个单元格里按 Ctrl+V：从这一格开始，向右、向下覆盖，行数不够时自动新增。只粘贴一个值时，按普通输入处理。
- 如果第一行是表头（至少一半的列能按列名或字段键对上），就按表头对应列，表头行本身不粘贴。
- 超出子表行数上限的部分不会粘贴，会提示有多少行没有粘贴。

## 取值转换与逐格校验

| 列类型 | 转换 |
|---|---|
| 数字 | 去掉千分位后转成数字 |
| 开关 | 是/否、true/false、1/0、Y/N、√/× |
| 日期 | 支持 `2026-11-10`、`2026/11/10`、`2026年11月10日` 和 Excel 日期序号 |
| 下拉、单选、字典、多选 | 按选项名称或取值匹配（不区分大小写，忽略空格） |
| 引用 | 按显示名称查找对象，同名多个或找不到时给出候选 |

- 对不上的单元格会标红，并显示「第 n 行：…」。下拉和引用列还会列出最多 3 个候选值（名称包含关系优先，其次按编辑距离排序），点候选即可改正。
- 对不上的数字、日期、开关和引用先留空，原文写在问题说明里；下拉列保留原文，方便和候选对照。
- 粘贴的行里没有给出的必填列，同样会标出来。
- 粘贴完成后提示「已粘贴 N 行，M 处需要修改」。提交时仍由服务端按表单校验。

同一字典在多个单元格中只请求一次（`dictCache`，缓存 1 分钟）。
