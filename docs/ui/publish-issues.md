# 发布前问题清单

审批流配置器与表单设计器的「校验」「发布」会列出问题清单：

- **分级**：错误（红）阻止发布；警告（黄）只提示，可以发布。错误排在前面，顶部显示"N 个错误 / M 个警告"。
- **一键定位**：点击问题项——
  - 节点问题：选中该节点，打开节点属性并滚动、高亮对应区块（字段策略、办理人、提交 Operation、超时、分支）；
  - 流程设置问题（编码、名称、发起动作、表单、回调）：滚动并高亮对应设置项；
  - 表单设计器：字段问题选中画布中的字段；规则、动作、节点策略问题切到对应面板并高亮那一项。
- 有错误时点「发布」提示"有 N 个错误，不能发布"；服务端发布同样只按错误拒绝。

审批流新增的警告：

| 代码 | 说明 |
|---|---|
| POLICY_MISSING | 人工节点未配置字段策略（表单上也没有该节点的策略）：办理人可修改所有可编辑字段 |
| TIMEOUT_MISSING | 人工节点未设置超时：待办可能长期无人办理 |
| ASSIGNEE_SCOPE_WIDE | 按角色分派未限定业务组织：其他组织的同角色人员也会收到待办 |
| CALLBACK_WITHDRAWN_MISSING | 未配置撤回回调：发起人提交后不能撤回 |

接口：`POST /api/flow/definitions/validate` 返回的每个问题带 `level`（ERROR / WARNING）。验证：`FlowGovernanceTest`、`tests/e2e/flow-issues.e2e.mjs`。
