# 偏好中心、收藏与最近访问

- **入口**：用户菜单 →「偏好设置」（`/user/prefs`）。
- **偏好项**：主题（跟随系统、浅色、深色）、密度（自动、舒适、紧凑）、导航布局（左侧、顶部、混合）、多页签、快捷键提示。
  修改即生效，并写回服务端（`ui_user_pref.prefs`，`PUT /api/ui/prefs`，只接受已知偏好项与取值）。上游的布局设置抽屉改动同样会同步。
- **收藏与最近访问**：命令面板中按 Ctrl/⌘+D 收藏；在对象详情页点「收藏」。最近访问保留 30 条。
  数据保存在 `ui_user_pref.nav`（`PUT /api/ui/prefs/nav`，只接受站内地址，最多收藏 100 条）。
  收藏显示在侧栏首页之后的「收藏」分组（台账记录类收藏只在命令面板中显示），以及命令面板的空输入状态。
- **登录与退出**：登录后先读取服务端偏好再进入页面，换浏览器或设备登录后保持。退出登录时清掉本机缓存的收藏与最近访问。
  本机缓存不区分用户，因此不会上传到服务端。
- **测试**：`PrefServiceTest`（集成），`tests/ui/app/prefs.spec.ts`（换浏览器登录后保持）。
